## 1. 项目概览

本系统是一套面向学校场景的教室预约与使用登记平台，采用前后端分离架构：

| 层 | 技术栈 |
|----|--------|
| 前端 | Vue 3 + Vite + Element Plus + Pinia + ECharts + SCSS |
| 后端 | Spring Boot 3.2 + MyBatis + JWT + SpringDoc OpenAPI |
| 数据库 | MySQL 8.0 |
| 缓存 | Redis 7 |
| 构建工具 | Maven（后端）/ npm + Vite（前端） |

系统提供三种角色：**学生 / 教师 / 管理员**，登录入口区分学生与教师/管理员两个 Tab，根据角色自动跳转到对应工作台。

## 4. 首次部署：从零启动

> 第一次运行项目时，按以下顺序执行。后续日常运行请直接看[第 5 节](#5-日常启动流程)。

### 4.1 初始化数据库

**步骤 1：启动 MySQL 服务**（若已运行可跳过）

```powershell
# Windows 服务方式（推荐）
net start MySQL80
```

**步骤 2：执行建库脚本**

```powershell
mysql --default-character-set=utf8mb4 -u root -p < "e:\教室预约与使用登记系统\阶段1-数据库\schema-and-data.sql"
```

脚本会自动完成：
- 删除并重建 `classroom_reservation` 数据库
- 创建 `classroom` `sys_user` `reservation` `usage_log` 四张表
- 写入初始教室数据（6 间）和测试用户数据（学生/教师/管理员各 1 个）

### 4.2 启动 Redis

```powershell
# 若已安装为 Windows 服务
net start Redis

# 或直接启动二进制
& "C:\Users\lenovo\redis-server.exe"
```

验证：看到 `Ready to accept connections` 或端口 6379 处于 LISTENING 即成功。

```powershell
# 验证端口
netstat -ano | findstr ":6379"
```

### 4.3 配置后端连接参数

打开 [backend/src/main/resources/application.yml](file:///e:/教室预约与使用登记系统/backend/src/main/resources/application.yml)，按本机实际情况修改数据库与 Redis 连接信息：

```yaml
spring:
  datasource:
    url: jdbc:mysql://127.0.0.1:3306/classroom_reservation?useUnicode=true&characterEncoding=utf8&serverTimezone=Asia/Shanghai&allowPublicKeyRetrieval=true&useSSL=false
    username: root
    password: 你的MySQL密码
  data:
    redis:
      host: 127.0.0.1
      port: 6379
      password:                       # 无密码可留空
```

> 也支持通过环境变量覆盖：`DB_HOST` `DB_PORT` `DB_USER` `DB_PASS` `REDIS_HOST` `REDIS_PORT` `REDIS_PASS`。

### 4.4 启动后端服务

```powershell
# 进入后端目录
cd e:\教室预约与使用登记系统\backend

# 启动（Maven 方式）
mvn spring-boot:run
```

首次启动会下载 Maven 依赖，约需 2-5 分钟。看到以下日志即启动成功：

```
Tomcat started on port(s): 8080 (http)
Started ClassroomReservationApplication in x.xxx seconds
```

验证端口：

```powershell
netstat -ano | findstr ":8080"
```

### 4.5 安装前端依赖并启动

```powershell
# 进入前端目录
cd e:\教室预约与使用登记系统\frontend

# 安装依赖（首次执行）
npm install

# 启动 dev server
npm run dev
```

看到 Vite 输出：

```
  VITE v5.x  ready in xxx ms

  ➜  Local:   http://localhost:5173/
  ➜  Network: use --host to expose
```

### 4.6 访问系统

浏览器打开 **http://localhost:5173** 即可看到登录页。

## 5. 日常启动流程

数据库只需初始化一次，日常启动只需按顺序启动 Redis → 后端 → 前端三步。

### 5.1 一键启动顺序

| 顺序 | 服务 | 命令 | 端口 |
|------|------|------|------|
| 1 | Redis | `net start Redis` 或运行 redis-server.exe | 6379 |
| 2 | MySQL | `net start MySQL80`（开机自启可跳过） | 3306 |
| 3 | 后端 | `cd backend; mvn spring-boot:run` | 8080 |
| 4 | 前端 | `cd frontend; npm run dev` | 5173 |

### 5.2 验证服务状态

```powershell
# 一次性检查三个关键端口
netstat -ano | findstr ":6379 :3306 :8080 :5173"
```

输出应包含 4 个 LISTENING 条目。

### 5.3 打开系统

- 前端地址：http://localhost:5173
- 后端 API 基础地址：http://localhost:8080/api
- Swagger 文档：http://localhost:8080/swagger-ui.html

## 6. 停止服务

### 6.1 前端 dev server

在运行 `npm run dev` 的终端窗口按 `Ctrl + C` 即可。

### 6.2 后端服务

在运行 `mvn spring-boot:run` 的终端按 `Ctrl + C`。

### 6.3 Redis / MySQL

```powershell
# 停止 Windows 服务
net stop Redis
net stop MySQL80
```

### 6.4 强制结束占用端口的进程

若服务异常未正常退出，可按端口定位并结束进程：

```powershell
# 查找占用 8080 的进程 PID
netstat -ano | findstr ":8080"
# 结束该 PID（替换 <PID>）
taskkill /PID <PID> /F
```

## 7. 生产构建与部署

### 7.1 前端打包

```powershell
cd e:\教室预约与使用登记系统\frontend
npm run build
```

产物输出到 `frontend\dist\`，可直接用 Nginx 托管：

```nginx
server {
    listen 80;
    server_name your-domain.com;
    root /path/to/frontend/dist;
    location / {
        try_files $uri $uri/ /index.html;
    }
    location /api/ {
        proxy_pass http://127.0.0.1:8080/api/;
    }
}
```

### 7.2 后端打包

```powershell
cd e:\教室预约与使用登记系统\backend
mvn clean package -DskipTests
```

产物：`backend\target\classroom-reservation-1.0.0.jar`

运行 jar 包：

```powershell
java -jar backend\target\classroom-reservation-1.0.0.jar
```

### 7.3 生产环境配置覆盖

通过环境变量或命令行参数覆盖默认配置：

```powershell
$env:DB_HOST="prod-db.example.com"
$env:DB_PASS="prod-password"
$env:REDIS_HOST="prod-redis.example.com"
java -jar backend\target\classroom-reservation-1.0.0.jar
```

## 10. 冒烟测试脚本

项目内置冒烟测试脚本 [scripts/smoke-test.ps1](file:///e:/教室预约与使用登记系统/scripts/smoke-test.ps1)，自动验证后端关键接口。

### 10.1 运行前提

- 后端服务已启动（端口 8080）
- 数据库已初始化（含初始测试数据）

### 10.2 执行方式

```powershell
powershell -ExecutionPolicy Bypass -File "e:\教室预约与使用登记系统\scripts\smoke-test.ps1"
```

### 10.3 预期输出

脚本会依次检查：
1. 后端服务存活（`/api/dashboard/stats`）
2. 登录接口（学生/教师/管理员三种账号）
3. 教室列表查询
4. 预约创建与查询
5. 审批流程
6. 使用登记签到签退

每个检查点输出 `[PASS]` 或 `[FAIL]`，最终汇总通过/失败数。

## 12. 常见问题排查

### 12.1 前端访问报 `net::ERR_CONNECTION_REFUSED`

**原因**：后端未启动或端口 8080 未监听。

**解决**：
1. 确认后端进程在运行：`netstat -ano | findstr ":8080"`
2. 查看后端启动日志是否有异常
3. 确认 [vite.config.js](file:///e:/教室预约与使用登记系统/frontend/vite.config.js) 中 proxy 配置指向 `http://localhost:8080`

### 12.2 后端启动报数据库连接失败

**原因**：MySQL 未启动、密码错误或库不存在。

**解决**：
1. 确认 MySQL 服务运行中：`net start MySQL80`
2. 核对 [application.yml](file:///e:/教室预约与使用登记系统/backend/src/main/resources/application.yml) 中的 `username` `password`
3. 确认已执行 [schema-and-data.sql](file:///e:/教室预约与使用登记系统/阶段1-数据库/schema-and-data.sql) 建库
4. 测试连接：`mysql -u root -p -e "USE classroom_reservation; SHOW TABLES;"`

### 12.3 后端启动报 Redis 连接失败

**原因**：Redis 未启动。

**解决**：
1. 启动 Redis：`net start Redis` 或运行 `redis-server.exe`
2. 验证端口：`netstat -ano | findstr ":6379"`
3. 若 Redis 设有密码，在 `application.yml` 的 `spring.data.redis.password` 填入

### 12.4 登录后立即被踢回登录页

**原因**：token 失效或后端 JWT 校验失败。

**解决**：
1. 浏览器 DevTools → Application → Local Storage 清除 `token` `user`
2. 重新登录
3. 若仍失败，检查后端日志中 JWT 校验异常，确认 `jwt.secret` 未被改动

### 12.5 前端构建报 SCSS 弃用警告

**现象**：`DEPRECATION WARNING [legacy-js-api]`

**原因**：使用旧版 Sass JS API。

**解决**：已在 [vite.config.js](file:///e:/教室预约与使用登记系统/frontend/vite.config.js) 配置 `css.preprocessorOptions.scss.api = 'modern-compiler'`，正常情况不会出现。若仍出现，确认 sass 版本 ≥ 1.70：

```powershell
npm ls sass
```

### 12.6 端口被占用

**现象**：`Port 8080 was already in use` 或 `5173 is in use`。

**解决**：

```powershell
# 查找占用进程
netstat -ano | findstr ":8080"
# 强制结束（替换 <PID>）
taskkill /PID <PID> /F
```

也可修改配置改用其他端口：
- 后端：修改 `application.yml` 的 `server.port`
- 前端：修改 `vite.config.js` 的 `server.port`，并同步更新 proxy target

### 12.7 Maven 命令找不到

**现象**：`mvn : 无法将"mvn"项识别为 cmdlet...`

**解决**：
1. 确认 Maven 已安装并配置 PATH
2. 或使用 Maven 目录的绝对路径调用：
   ```powershell
   & "C:\Users\lenovo\apache-maven-3.9.16\bin\mvn.cmd" spring-boot:run
   ```

### 12.8 数据库初始数据丢失

**原因**：手动删除或误操作。

**解决**：重新执行建库脚本即可（会清空重建）：

```powershell
mysql --default-character-set=utf8mb4 -u root -p < "e:\教室预约与使用登记系统\阶段1-数据库\schema-and-data.sql"
```
