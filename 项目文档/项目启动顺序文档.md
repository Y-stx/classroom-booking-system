# 教室预约与使用登记系统 - 项目启动顺序文档

> 本文档说明项目各部分的启动顺序与命令，匹配实际开发环境（前端用 VSCode，后端用 IDEA）。

---

## 一、启动顺序总览

项目采用前后端分离架构，启动顺序如下（**必须按此顺序**）：

| 顺序 | 服务 | 端口 | 启动位置 | 说明 |
|------|------|------|----------|------|
| 1 | MySQL | 3306 | 系统服务 | 数据存储（首次需初始化数据库） |
| 2 | Redis | 6379 | 直接运行 exe | 缓存与会话（JWT Token 存储） |
| 3 | 后端 Spring Boot | 8080 | IDEA | 提供 API 接口 |
| 4 | 前端 Vite | 5173 | VSCode | 提供 Web 界面 |

> 前端依赖后端 API，后端依赖 MySQL 与 Redis，因此必须按上述顺序启动。

## 二、首次启动（全新环境）

### 1. 启动 MySQL 服务

```powershell
net start MySQL80
```

### 2. 初始化数据库（仅首次执行）

```powershell
mysql --default-character-set=utf8mb4 -u root -p < "e:\教室预约与使用登记系统\阶段1-数据库\schema-and-data.sql"
```

输入 MySQL 密码后回车，脚本会自动建库建表并写入初始数据。

### 3. 启动 Redis

```powershell
Start-Process -FilePath "C:\Users\lenovo\redis-server.exe" -WindowStyle Hidden
```

验证端口：
```powershell
netstat -ano | findstr ":6379"
```

### 4. 配置后端连接参数

打开 [backend/src/main/resources/application.yml](file:///e:/教室预约与使用登记系统/backend/src/main/resources/application.yml)，核对以下信息：

```yaml
spring:
  datasource:
    url: jdbc:mysql://127.0.0.1:3306/classroom_reservation?useUnicode=true&characterEncoding=utf8&serverTimezone=Asia/Shanghai&allowPublicKeyRetrieval=true&useSSL=false
    username: root
    password: 你的MySQL密码          # 当前配置为 yky060425
  data:
    redis:
      host: 127.0.0.1
      port: 6379
      password:                       # 无密码留空
```

### 5. 在 IDEA 中启动后端

**前置：** 在 IDEA 中打开 `e:\教室预约与使用登记系统\backend` 文件夹，等待 Maven 自动下载依赖完成（首次约2-5分钟）。

**启动方式（任选其一）：**

- **方式A（推荐）：运行主类**
  1. 在 IDEA 项目树中找到 `src/main/java/com/classroom/reservation/ClassroomReservationApplication.java`
  2. 右键 → `Run 'ClassroomReservationApplication'`

- **方式B：使用 Maven 命令**
  1. 在 IDEA 底部打开 `Terminal` 终端面板
  2. 执行命令：
  ```powershell
  mvn spring-boot:run
  ```

**启动成功标志：**

IDEA 控制台输出以下内容即启动成功：

```
Tomcat started on port(s): 8080 (http)
Started ClassroomReservationApplication in x.xxx seconds

╔══════════════════════════════════════════════╗
║   教室预约与使用登记系统后端启动成功!          ║
║   Swagger: http://localhost:8080/swagger-ui   ║
╚══════════════════════════════════════════════╝
```

### 6. 在 VSCode 中安装前端依赖（仅首次执行）

**前置：** 在 VSCode 中打开 `e:\教室预约与使用登记系统\frontend` 文件夹。

**操作：**

1. 在 VSCode 中打开终端（快捷键 `` Ctrl + ` `` 或菜单 `Terminal → New Terminal`）
2. 执行命令：
```powershell
npm install
```

> 首次执行会下载所有前端依赖，约需1-3分钟，请耐心等待。

### 7. 在 VSCode 中启动前端

在 VSCode 终端中执行：

```powershell
npm run dev
```

**启动成功标志：**

终端输出以下内容即启动成功：

```
  VITE v5.x  ready in xxx ms

  ➜  Local:   http://localhost:5173/
  ➜  Network: use --host to expose
```

### 8. 访问系统

浏览器打开 **http://localhost:5173** 即可看到登录页。

## 三、日常启动（已初始化过）

数据库只需初始化一次，日常启动按以下顺序：

#### 步骤 1：启动 MySQL（若已开机自启可跳过）

```powershell
net start MySQL80
```

#### 步骤 2：启动 Redis

```powershell
Start-Process -FilePath "C:\Users\lenovo\redis-server.exe" -WindowStyle Hidden
```

#### 步骤 3：在 IDEA 中启动后端

1. 打开 IDEA（已加载 backend 项目）
2. 右键 `ClassroomReservationApplication.java` → `Run`
   - 或在 IDEA Terminal 执行：`mvn spring-boot:run`
3. 等待控制台输出"后端启动成功"

#### 步骤 4：在 VSCode 中启动前端

1. 打开 VSCode（已加载 frontend 项目）
2. 打开终端（`` Ctrl + ` ``）
3. 执行：`npm run dev`
4. 等待 Vite 输出 `ready`

#### 步骤 5：浏览器访问

```
http://localhost:5173
```

## 四、一键验证所有服务

打开任意终端（VSCode 或 PowerShell）执行：

```powershell
netstat -ano | findstr "LISTENING" | findstr ":6379 :3306 :8080 :5173"
```

输出应包含 4 个 LISTENING 条目（3306/6379/8080/5173），表示全部服务就绪。

## 六、停止服务

| 服务 | 停止方式 |
|------|----------|
| 前端 | 在 VSCode 终端按 `Ctrl + C`，输入 `Y` 确认 |
| 后端 | 在 IDEA 控制台点击红色方块停止按钮 ■，或按 `Ctrl + F2` |
| Redis | 关闭 redis-server 进程（任务管理器或 taskkill） |
| MySQL | `net stop MySQL80` |

**强制结束占用端口的进程：**

```powershell
# 查找占用 8080 的进程 PID
netstat -ano | findstr ":8080"
# 结束该 PID（替换 <PID>）
taskkill /PID <PID> /F
```

## 八、开发环境说明

| 工具 | 用途 | 打开的项目路径 |
|------|------|----------------|
| **IDEA** | 后端开发与运行 | `e:\教室预约与使用登记系统\backend` |
| **VSCode** | 前端开发与运行 | `e:\教室预约与使用登记系统\frontend` |

**建议工作流：**

1. 两个编辑器同时打开，IDEA 运行后端，VSCode 运行前端
2. 后端改动后会自动重启（Spring Boot DevTools），无需手动停止
3. 前端改动后 Vite 会热更新（HMR），浏览器自动刷新页面
4. Swagger 文档可在线测试 API：http://localhost:8080/swagger-ui.html
